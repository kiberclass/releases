# Kiberclass: выпуски

Установщики Kiberclass для Windows 10 и 11 x64. Исходный код в закрытом
репозитории, здесь только готовые сборки.

- **Kiberclass-Teacher-Setup-*.exe**: консоль учителя.
- **Kiberclass-Student-Setup-*.exe**: программа для компьютеров учеников.

Берите установщики со страницы [последнего выпуска](https://github.com/kiberclass/releases/releases/latest).
Ставить их нужно только один раз: консоль обновляется отсюда сама, а компьютеры
учеников обновляет консоль.

Установщики не подписаны сертификатом Microsoft, поэтому при первом запуске
Windows SmartScreen покажет предупреждение: «Подробнее», затем «Выполнить в любом случае».
