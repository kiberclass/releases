# Kiberclass

Управление компьютерным классом в локальной сети. Учитель ведёт урок из одной
консоли: видит экраны учеников, показывает свой, раздаёт материалы и собирает
работы. Интернет и отдельный сервер не нужны, всё работает внутри сети класса.

**[Скачать последнюю версию](https://github.com/kiberclass/releases/releases/latest)**

## Возможности

- **Весь класс на одном экране.** Кто на связи и кто за каким компьютером сидит.
  Плитки расставляются перетаскиванием, как стоят парты.
- **Экраны учеников.** Видео в реальном времени, управление мышью и клавиатурой
  ученика.
- **Показ экрана учителя** выбранным ученикам или всему классу.
- **Блокировка и питание.** Заблокировать компьютеры с текстом на экране,
  выключить, перезагрузить, включить по сети.
- **Сайты и программы.** Открыть сайт или запустить программу из меню «Пуск»
  у всех сразу, закрыть лишнее.
- **Материалы и работы.** Раздать файлы к уроку и собрать работы обратно.
  Ученик сдаёт работу, перетащив файл в окно.
- **Сообщения, звук и яркость** на компьютерах учеников.
- **Быстрая панель** с частыми командами поверх всех окон.

## Установка

Нужны Windows 10 или 11 x64 на всех компьютерах, в одной локальной сети.

1. На компьютер учителя поставьте **Kiberclass-Teacher-Setup-*.exe**.
2. На каждый компьютер ученика поставьте **Kiberclass-Student-Setup-*.exe**.
   Программа работает службой Windows, ученик не может её закрыть.
3. В консоли нажмите «Добавить компьютеры» и введите показанный код в окне
   ученика. Одним кодом подключается весь класс.

Установщики не подписаны сертификатом Microsoft, поэтому при первом запуске
Windows SmartScreen покажет предупреждение: «Подробнее», затем «Выполнить в любом
случае».

## Обновления

Ставить программы нужно только один раз. Консоль сама проверяет новые версии в
этом репозитории, а компьютеры учеников обновляет по локальной сети. Каждое
обновление подписано, чужую сборку программы не примут.

Исходный код закрыт, здесь только готовые сборки.
